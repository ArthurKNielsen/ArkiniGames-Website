# Arkini Games

**Live site:** https://arthurknielsen.github.io/ArkiniGames-Website/

The official website of Arkini Games, a one-person game studio in Aarhus, Denmark.

The site boots like an old PS1: a BIOS screen, a memory card menu with every game
as a save, and a disc that spins up when you open one. On the KRAVN page you fall
down a shaft as you scroll and land on the Steam wishlist button.

## KRAVN

A fast, gory boomer shooter where your only weapon is a stick that always comes back.
